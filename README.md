# SyncSphere Prototype

Frontend-only prototype for a student social app focused on making friends, building hobbies, and improving speaking confidence.

## What is in this project

- `index.html`: Login screen for the prototype flow.
- `dashboard.html`: Main phone-style app shell with top bar, content area, and bottom tab navigation.
- `app.js`: Client-side app logic, page rendering, timetable compare logic, and mock interactions.
- `styles.css`: Mobile-first UI styling (phone frame layout, cards, tab bar, chat, timetable components).
- `vercel.json`: Vercel rewrites for clean routing to `index.html` and `dashboard.html`.
- `package.json`: Minimal project metadata and local static serve script.

## Included app sections

- Home
- SyncQuests
- Events
- SyncTime (My Timetable, Compare, SyncPlan)
- Direct Messages
- My Profile
- Settings (top bar)

## Prototype scope

- No backend
- No real authentication
- Uses mock/static data
- Uses localStorage for basic user name persistence
